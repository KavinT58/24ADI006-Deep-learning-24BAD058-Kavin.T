## Project Description
An educational chatbot built using a pretrained Transformer-based
Large Language Model. It answers questions and uses conversation
history to handle follow-up questions.

## Technologies Used
- Python
- PyTorch
- Hugging Face Transformers
- Qwen2.5-1.5B-Instruct
- Gradio
- Google Colab

## Features
- Answers educational questions
- Explains technical concepts
- Compares programming languages
- Handles follow-up questions
- Provides a web-based chat interface

## How to Run
1. Install the libraries listed in requirements.txt.
2. Run app.py.
3. Wait for the model to load.
4. Open the Gradio link displayed in the terminal.

## Limitations
- Responses may occasionally be inaccurate.
- The model requires sufficient memory.
- Internet access is required to download the pretrained model
  when it is not already cached.
